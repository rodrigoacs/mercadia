# 🏛️ Mercadia

O terminal financeiro e gestor definitivo para coleções e decks de **Magic: The Gathering**. 

## 🚀 Funcionalidades
- **Análise de Coleção**: Obtenha insights detalhados sobre a composição, valor e raridade da sua coleção.
- **Gestão de Decks**: Organize seus decks, acompanhe o desempenho e preços.
- **Monitoramento de Preços**: Fique atualizado com as últimas tendências de preços e valores de mercado.
- **Interface Intuitiva**: Navegação fácil e design moderno para uma experiência fluida.
